02 · Biography

Richard William McLean / Barran Dodger

The public archive uses both Richard William McLean and Barran Dodger. Public catalogue material describes the archive subject as an artist, author, researcher, academic and advocate. 05 · Evidence centre

Evidence architecture

Primary evidence

Original documents and source records.

Official record

Government correspondence, FOI releases, proceedings and administrative records.

Independent corroboration

Material from independent sources capable of supporting or challenging an assertion.

Author record

Statements and testimony originating from the author.

Secondary material

News, commentary and other secondary sources.

Interpretation

Analytical, theological or theoretical interpretation.

Unverified claim

A claim whose underlying proposition has not been independently established.

Core rule: a filename is not a finding; a hyperlink is not corroboration; a Git object is not proof of document contents; a blockchain timestamp can establish existence of data at a time but does not by itself establish the truth of its contents.

09 · Verification

Independent checking protocol

1. Existence

Confirm the repository path exists.

2. File type

Distinguish a complete PDF from a pointer/stub.

3. Size

Compare actual object size with any manifest.

4. SHA-256

Hash the actual complete file where available.

5. Provenance

Record where the document came from.

6. External comparison

Compare with an original issuing source where possible.

7. Status

Label official record, author account, allegation, analysis or unresolved claim.

8. Reproducibility

Another researcher should be able to repeat the check.

10 · Methodology

Research method

Preserve

Preserve the original document and identifying information.

Catalogue

Assign a category and stable record identifier.

Cross-reference

Connect documents, dates, agencies, people and responses.

Verify

Use source provenance, file inspection and hashes where possible.

Separate

Never merge testimony or analysis into an official finding.

Preserve access

Use redundant public nodes where legally and technically appropriate.

State uncertainty

Unresolved material remains unresolved.

Allow challenge

Contradictory evidence and corrections should remain discoverable.

Evidence hierarchy: judicial/official determination → primary government record → contemporaneous primary document → independent corroboration → author record → secondary source → interpretation → unverified claim.

12 · Evidentiary notice

Read the record, not merely the assertion

This archive may contain official documents, author testimony, allegations, interpretations, AI-assisted analyses, historical material and secondary sources.

A document can establish that a statement was made or that a record exists without establishing the truth of every assertion within it. Inclusion of a person, organisation or allegation does not itself establish wrongdoing, liability or causation.

The purpose of the archive is preservation, traceability and independent research.
