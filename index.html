Independent examination

Verification

The archive does not ask readers to accept every conclusion. It asks them to examine the underlying evidence.

If a document is misrepresented, identify it and show where.

If a decision is misunderstood, show the correct interpretation.

If a chronology is wrong, correct it with primary evidence.

If a legal proposition is wrong, cite the authority and explain why.

Do not answer allegation with assertion. Answer document with document, date with date, decision with decision.
