DOCUMENT STATUS: PUBLIC ARCHIVE ANALYTICAL REPORT
METHOD: FULL DETAIL / NO COMPRESSION / PRESERVE ITEMISATION
EVIDENCE PRINCIPLE: DOCUMENT THE RECORD; DISTINGUISH RECORD FROM TESTIMONY, ALLEGATION, INFERENCE, INTERPRETATION AND UNRESOLVED MATTERS.

IMPORTANT LIMITATION
This report is a structured analytical reconstruction of material exposed through the public Barran Dodger archive and the public repository structure. It does not convert archive assertions into judicial findings. Where a proposition is not independently established, it is labelled accordingly. Counts appearing on different archive pages may represent different inventories, dates, repositories or verification stages and are not silently reconciled.

STANDARD EVIDENCE CLASSIFICATION
A — DOCUMENTED FACT: Supported directly by a reliable primary record or authoritative determination.
B — CORROBORATED CLAIM: Supported by more than one independent or materially corroborating source without necessarily constituting an official finding.
C — DOCUMENTED ALLEGATION: Recorded in a complaint, statement, correspondence or other document but not independently established.
D — INFERENCE: A conclusion drawn from documented circumstances rather than directly established.
E — INTERPRETATION: Analytical, legal, philosophical or theological interpretation.
F — UNRESOLVED: Evidence is incomplete, conflicting, unavailable or insufficient for a stronger classification.

CORE EVIDENCE COMMAND
CLAIM → IDENTIFY → SOURCE → DATE → ACTOR / INSTITUTION → PRIMARY RECORD → CORROBORATION → CONTRADICTORY / LIMITING EVIDENCE → OFFICIAL RESPONSE → FINDING STATUS → LEGAL / ANALYTICAL FRAMEWORK → CONSEQUENCE → VERIFICATION → PRESERVATION.

PROVENANCE COMMAND
SOURCE → ORIGINAL FILE → ORIGINAL FILENAME → REPOSITORY → PATH → ACQUISITION DATE → PUBLICATION DATE → HASH → GIT COMMIT → GIT BLOB → TIMESTAMP / SEAL → VERSION HISTORY → RELATED RECORDS → PUBLIC LINK.

REPORT 5 — CONTRADICTIONS, DISCREPANCIES AND UNANSWERED QUESTIONS

PRIMARY FUNCTION
To create a dedicated evidence-testing register for contradictions, changed explanations, inconsistent dates, missing records, disputed classifications, unexplained discrepancies and unanswered correspondence.

CONTRADICTION TEST
A contradiction should only be called a contradiction after confirming that the two records answer the same question, concern the same person or event, operate within the same relevant timeframe, and are not merely describing different stages of a process.

STANDARD ENTRY
CONTRADICTION ID; PROPOSITION A; SOURCE A; DATE A; PROPOSITION B; SOURCE B; DATE B; SAME QUESTION?; SAME TIMEFRAME?; SAME RECORD?; NATURE OF DISCREPANCY; POSSIBLE EXPLANATIONS; CORROBORATION; LIMITING EVIDENCE; OFFICIAL RESPONSE; CURRENT STATUS.

1. DOCUMENT COUNT DISCREPANCIES
The archive has displayed multiple counts across pages and repositories. This is a documented inventory discrepancy, not necessarily a substantive contradiction. Possible explanations include different dates, deduplication rules, repository scope, file types and verification stages.

2. DOWNLOAD COUNT DISCREPANCIES
Public pages may expose different download totals at different times. Such figures are time-sensitive usage statistics and should be dated rather than treated as fixed archive size.

3. PDF / DOCUMENT INVENTORY DIFFERENCES
One page may count PDFs, another primary sources, another verified exhibits, another repository files. The reconciliation task is to define the denominator before comparing figures.

4. MEDICAL CLASSIFICATION DIFFERENCES
Where diagnoses or classifications differ, record the exact wording, clinician, date, context and whether the later record is a correction, different assessment or retrospective interpretation.

5. LEGAL STATUS DIFFERENCES
A complaint, application, submission, determination, appeal and judicial finding are different legal events. Apparent contradiction can arise if later summaries collapse them.

6. CORPORATE RECORD DISCREPANCIES
Compare entity name, ACN/ABN, dates, officeholders, addresses, lodged documents and status. An identity mismatch may arise from common names or data-entry errors and must be investigated before stronger conclusions.

7. EMPLOYMENT STATUS
Compare contemporaneous employment records with later administrative descriptions. The 27 March 2023 correspondence should be treated as a discrete official correspondence record; it should not be generalized beyond its wording.

8. PID RECORD
Separate the number of allegations contained in a PID from the number independently established. A PID acknowledgement establishes processing, not substantive truth.

9. FINANCIAL CALCULATION DISCREPANCIES
Every total must be reconstructed from components. Test for overlapping periods, duplicated losses, projected amounts included as actual losses, and causation assumptions.

10. TIMELINE DISCREPANCIES
When a later narrative gives a date different from a contemporaneous document, privilege the contemporaneous record provisionally while preserving the discrepancy and checking whether the later date refers to a different event.

11. UNANSWERED CORRESPONDENCE
Record the exact question, recipient, date sent, receipt evidence, response deadline, response received, follow-up and current status. An unanswered question is not itself evidence of the answer.

12. MISSING RECORDS
Document the expected holder, search performed, FOI request if any, stated retention period, secondary references and possible reasons for absence.

13. CHANGED EXPLANATIONS
A changed explanation should be compared line by line. Possible explanations include new evidence, correction, different question, different decision-maker, or inconsistency. Do not assign motive without evidence.

14. CONTRADICTION SEVERITY
For internal use classify as: clerical discrepancy; date discrepancy; terminology difference; material inconsistency; direct contradiction; unresolved. Avoid rhetorical escalation.

15. ANSWERABILITY
For every unresolved issue ask whether it can be resolved by a primary document, independent registry search, FOI record, court order, transcript, financial statement, medical record, metadata or witness evidence.

16. FINAL CONTRADICTION REGISTER
The public-facing version should allow the reader to open both documents side by side and see exactly what differs.


DOCUMENTARY WARNING
The existence of a document establishes that the document exists. It does not automatically establish the truth of every statement inside it. A complaint establishes that a complaint was made; it does not itself establish the complained-of conduct. A court filing establishes that a filing occurred; it does not establish that the court accepted every proposition. A government record establishes what the government recorded or communicated; it does not necessarily establish that every interpretation of that record is correct. A blockchain timestamp can assist with integrity and chronology; it does not establish the substantive truth of a document.

READER TEST
For every significant proposition ask: Who says this? When did they say it? What did they rely upon? Is the original record available? Was it contemporaneous? Is there independent corroboration? Is there contradictory evidence? Did a competent authority make a finding? What remains unresolved?

EVIDENCE AUDIT CHECKLIST

1. Every major proposition has a unique Evidence ID.
    2. The original document or authoritative source is identified.
    3. The public-facing source link is named and retained.
    4. The document date is distinguished from upload/publication date.
    5. The institution and individual role are recorded precisely.
    6. The evidence classification does not exceed what the source supports.
    7. Allegations are not silently converted into findings.
    8. Later interpretations are not substituted for contemporaneous records.
    9. Independent corroboration is identified separately from repository duplicates.
    10. Contradictory or limiting evidence is disclosed.
    11. Financial figures are reproducible from source records.
    12. Causation is distinguished from temporal sequence.
    13. Institutional knowledge is supported by receipt/acknowledgement evidence.
    14. Legal frameworks are identified without asserting a legal conclusion beyond the source.
    15. Privacy status is recorded before publication.
    16. Repository provenance and version history are preserved.
    17. The reader can return to the primary document without relying on AI summary.
    18. Unresolved questions remain visible rather than being rhetorically closed.

READER INDEPENDENCE STATEMENT

The purpose of this report is to increase the inspectability of the record. A reader should be able to disagree with the archive’s interpretation while still having direct access to the underlying material. The report therefore separates documentary existence, substantive content, corroboration, official findings and interpretation. The final determination of contested facts belongs to the appropriate evidence-review, regulatory, judicial or other competent process.
