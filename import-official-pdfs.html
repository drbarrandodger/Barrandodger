Easiest method: official PDFs → GitHub

Google Drive files are not public. The site must link to GitHub binary copies. This connector can download from Drive and catalogue pages, but cannot push binary PDFs into GitHub (text-only API).

Already done for you: 138 official government evidence PDFs are already binary-hosted on GitHub Backup and listed on the Official gov PDFs page.

Fastest path for remaining Drive PDFs

  1. On your computer, open Google Drive and select official government PDFs (or download a folder as ZIP).
  2. Open this GitHub upload page (logged in as wezzo72):
    Upload to government-evidence folder
  3. Drag-and-drop the PDFs (multiple files at once). Commit to main.
  4. Message here after upload — the site index will be refreshed with public raw links for every new file.

Alternative: local git (bulk / ZIP unpack)

  1. git clone https://github.com/wezzo72/Backup.git
  2. Copy PDFs into client/public/documents/government-evidence/Government Evidence/
  3. git add -A && git commit -m "Add official government PDFs" && git push

Why not Drive links on the public site?

Private Drive files show “request access” for visitors. Only GitHub (or another public host) works for a permanent forensic archive without login.
