Museum Method

How this archive works

This rebuild follows the master website command from 19 September 2026. It does not invent biography, crimes, or dollar figures.

Rules in force

  • Preserve the primary record. Do not rewrite a source PDF.
  • Label documented fact separately from author allegation.
  • A file titled Official is a document, not a finding that an allegation is true.
  • Economic estimates must stay estimates.
  • Theological writing stays the author’s writing.
  • Personal service files appear only because the archive owner asked.

Where files are stored

Presentation pages live in wezzo72/Barrandodger. Most PDFs already live in wezzo72/Backup. Google Drive is an extra store, not the public host.

What this rebuild is not

It is not a completed 79-section museum with checkout, hash verification and a full search engine. It is the public architecture plus the catalogues that can be built on GitHub Pages for free.
