# Data model (Phase 1 schema only)

Stable ID prefixes:
- CLM- claim
- DOC- document
- PER- person
- ORG- organisation
- EVT- event
- LAW- law or policy
- CST- cost item
- PUB- publication

Required fields for a document row: id, title, date, source, original_path, archive_path, classification, evidence_status.
Do not invent IDs for files that have not been inventoried.
