# Architecture

Presentation layer: static HTML + CSS on GitHub Pages (`wezzo72/Barrandodger`, branch `main`, root).
`.nojekyll` is present. Do not introduce a framework unless the existing static site cannot carry a phase.

Evidence layer: original files stay in `wezzo72/Backup` and `drbarrandodger/barran-dodger-archive`. Do not overwrite primary PDFs.

Google Drive is an external store. Metadata may be listed. Binaries are not copied unless a later phase can do so without altering the original.
